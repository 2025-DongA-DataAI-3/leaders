# 📈 TrendPilot (팀명: TheLeaders)

<br>

> **GPT-5.4-mini와 뉴스 데이터를 활용한 AI 기반 창업 준비 지원 서비스**
> <br> 트렌드를 읽고, 창업을 쓰다

<br>

## 👀 서비스 소개

**서비스명:** TrendPilot

**서비스 설명:** 뉴스 데이터 기반으로 창업 트렌드 키워드를 분석하고, 사용자 맞춤형 정부 지원 사업 공고 매칭과 AI 사업계획서 자동 생성까지 한 번에 지원하는 AI 기반 창업 준비 원플로우 플랫폼입니다.
Naver DataLab API · KeyBERT · Ko-SRoBERTa 기반 키워드 파이프라인과 GPT-5.4-mini / GPT-4o를 결합하여 예비 창업자의 아이템 발굴부터 사업계획서 완성까지 전 과정을 하나의 흐름으로 지원합니다.

<br>

## 📅 프로젝트 기간

**2026.04.30 ~ 2026.06.30 (9주)**
<br> K-Digital Training 선도기업 아카데미 동아 MX School 3기 · 데이터와 AI 융합 미디어 혁신 과정

<br>

## 💡 기획 배경

전체 창업기업 수는 5년 연속 감소하고 있으나 1인 창조기업은 전년 대비 **15.4% 증가**하며 개인 중심의 창업 수요는 오히려 확대되고 있습니다.
그러나 예비 창업자는 아래 세 가지 구조적 장벽에 노출되어 있습니다.

| 장벽 | 내용 |
|------|------|
| 📉 트렌드 파악 어려움 | 빠르게 변하는 시장에서 유망 아이템을 개인이 직접 발굴·분석하기 어려움 |
| 📂 공고 파편화 | 2026년 기준 111개 기관 508개 지원사업이 K-Startup·기업마당·지자체 홈페이지 등에 분산 |
| 📄 사업계획서 작성 부담 | 공고별 상이한 양식과 전문 역량 요구로 초기 창업자의 진입장벽으로 작용 |

> TrendPilot은 이 세 단계를 하나의 흐름으로 연결하는 **창업 준비 원플로우 플랫폼**입니다.

<br>

## ⭐ 주요 기능

#### 🗺️ 창업 트렌드 버블맵
뉴스 데이터 기반 창업 트렌드 키워드 버블 맵 시각화
> 네이버 검색어 트렌드 API 기반 씨드 키워드 선정 → 뉴스 크롤링 → Kiwi 형태소 분석 → KeyBERT + Ko-SRoBERTa 키워드 추출 → GPT-5.4-mini KEEP/REVIEW/DROP 분류 → D3.js 버블맵 시각화

#### 🏆 키워드 랭킹 TOP 10
검색량 증가율·기사 수·검색 관심도 등 5개 지표 가중 점수 기반 TOP 10 랭킹
> 검색 관심도·검색 증가율·뉴스 근거량·문서 관련도·최신성 5개 지표 Min-Max 정규화 후 가중합 → ranking_score 기준 TOP 10 출력

#### 🔍 키워드 분석 페이지
창업 키워드 트렌드 이유 · 추천 창업 아이템 · 시장 현황 · 관련 정책 · 관련 뉴스 5개 상세 분석
> GPT-5.4-mini + 별도 LLM 시장현황 분석

#### 📋 사용자 맞춤형 공고 추천
정부지원사업 공고 필터링 및 북마크
> 대상 구분·업력·지역 3가지 조건 입력 → K-Startup API 공고 데이터 매칭 점수 산정 (항목별 1점, 최대 3점) → 3점 이상 공고 필터링 출력

#### 📝 AI 사업계획서 자동 생성
사용자가 업로드한 사업계획서 양식 기반 가안 작성
> 양식 PDF/HWP 업로드 → GPT-4o-mini 섹션 구조 추출 → 9종 섹션 유형 분류 → GPT-4o 본문 자동 생성

#### 💬 커뮤니티
자유게시판 · 구인구직 · 법률 게시판 (CRUD + 댓글)

#### 🔐 소셜 로그인
카카오 · 구글 · 네이버 OAuth

## 🔄 서비스 흐름도

```
씨드 키워드 선정 (Naver DataLab API - 실제 검색량 기반)
        ↓
뉴스 수집 (씨드 키워드 기반 네이버 뉴스 크롤링)
        ↓
전처리 (Kiwi - 본문 정제 + 형태소 분석 + 불용어 제거)
        ↓
키워드 추출 (KeyBERT + Ko-SRoBERTa Multitask 임베딩)
        ↓
GPT 키워드 분류 (GPT-5.4-mini → KEEP / REVIEW / DROP)
        ↓
버블맵 시각화 (KEEP 키워드 + 씨드 키워드 → D3.js)
        ↓
키워드 클릭 → 분석 페이지 (트렌드 이유 / 추천 아이템 / 시장현황 / 관련 정책 / 관련 뉴스)
        ↓
사용자 조건 입력 → 맞춤형 공고 추천 (K-Startup API 매칭)
        ↓
양식 업로드 → AI 사업계획서 자동 생성 (GPT-4o-mini 구조 추출 → GPT-4o 본문 생성)
```

## 🔧 트러블 슈팅

#### 1. 데이터 수집 — 창업 관련 뉴스 연관성 부족

- **문제:** 초기 뉴스 수집용 검색어가 창업 아이템과 직접적인 연관성이 낮아 추출된 키워드의 창업 아이템 연관도가 떨어지는 문제가 발생하였다.
- **원인:** 검색어 선정 시 정량적 기준 없이 임의로 선정하다 보니, 선정된 검색어가 '창업'이라는 포괄적 개념에 머물렀고 구체적인 창업 아이템 유형을 반영하지 못하였다.
- **해결:** 네이버 검색어 트렌드 API로 실제 검색량을 검증해 최종 검색어를 선정하였다. 선정 검색어로 뉴스 데이터를 재수집하고 키워드를 재추출해 창업 아이템 관련 키워드 비율 개선을 확인하였다. 최종 검색어는 씨드 키워드로 활용해 키워드 맵의 기본 구성 요소로 사용하였다.
- **결과:** 창업 아이템과의 연관성이 높은 씨드 키워드를 정량적 기준으로 선정할 수 있게 되었다.

#### 2. AI / Data 분석 — 추출 키워드 연관성 부족

- **문제:** KeyBERT와 BERTopic으로 추출한 키워드 중 기사 본문의 전체 의미를 잘 담지 못하는 단어들이 추출 키워드 리스트에 포함되었다. 또한 BERTopic은 키워드 간 연결 작업에 활용하려 했으나 해당 용도로는 사용이 어려웠다.
- **원인:** KeyBERT에 형태소 분석된 단어 형태의 데이터만 입력하다 보니 본문 전체 문맥이 반영되지 않아 대표성이 낮은 키워드가 추출되었다. BERTopic은 문서를 토픽별로 묶는 방식이라 키워드 간 직접 연결 구조를 만들기에는 한계가 있었다.
- **해결:** 형태소 분석된 단어를 후보 키워드로, 노이즈 제거만 한 문장 형태의 본문을 함께 입력해 본문을 잘 대표하는 키워드가 추출되도록 수정하였다. 추출된 키워드 리스트를 LLM 모델에 입력해 창업 아이템과 연관성 있는 키워드만 선별하였다. BERTopic은 파이프라인에서 제외하고, 씨드 키워드를 카테고리 컬럼으로 활용해 씨드 키워드와 추출 키워드를 연결하였다.
- **결과:** 창업 아이템 연관도가 높은 키워드 추출이 가능해졌고 버블맵 연결 구조가 안정화되었다.

#### 3. Backend / DB — 회원 탈퇴 기능 구현 오류

- **문제:** 회원탈퇴 API 호출 시 users 테이블에서 유저 데이터 삭제가 실패하였다.
- **원인:** users 테이블을 참조하는 자식 테이블 11개(business_plans, chat_logs, comments, notifications, post_bookmarks, posts, reports 등)에 `ON DELETE CASCADE` 옵션이 설정되어 있지 않아, 부모 레코드(users) 삭제 시 참조 무결성 제약 위반 에러가 발생하였다.
- **해결:** 11개 자식 테이블 전체의 외래키 제약조건을 `ALTER TABLE`로 재설정하여 `ON DELETE CASCADE` 옵션을 추가하였다.
- **결과:** users 레코드 삭제 시 연관된 모든 자식 테이블의 데이터가 자동으로 함께 삭제되도록 처리되었다.

## 🚀 향후 발전 방향

#### ✅ 현재 MVP
- 뉴스 기반 키워드 분석 및 버블맵 시각화
- MySQL 기반 맞춤형 공고 추천
- AI 사업계획서 자동 생성

#### 🔧 기능 고도화
- 뉴스데이터 누적을 통한 키워드맵 동적 구성 (고정 키워드 → 데이터 축적 기반 동적 갱신)
- 성향진단 단계 사업 분야·보유 기술·창업 아이디어 데이터를 LLM으로 분석하는 추천 정밀도 향상
- Vector DB 고도화 (Chroma → Qdrant) 기반 공고 본문 시맨틱 검색 고도화

#### 🌐 서비스 확장
- 공고 추천 대상 확장 (예비창업자 → 기업 대상 정부지원공고)
- 트렌드 분석 데이터 B2B 제공 (컨설팅사·마케팅·언론홍보대행사 대상)
- 스타트업 시장분석 / 투자 유망 산업 탐색 플랫폼으로 확장
- 대학·창업교육기관 연계 교육 콘텐츠 플랫폼화
